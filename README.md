## Développement local

Ce portfolio est construit avec [Next.js](https://nextjs.org).

### Installation

```bash
npm run dev
# ou
yarn dev
```

Ouvrir [http://localhost:3000](http://localhost:3000) pour voir le résultat.

Les modifications dans `app/page.tsx` sont reflétées instantanément.
